# Habit Tracker 3.0 🚀

A revolutionary PHP CodeIgniter-based tracking system for those who want to break bad habits. The application offers regular monitoring of habits, graphical presentation of progress, and a motivating level system with cutting-edge glassmorphism design.

## ✨ Features

### 🔄 Revolutionary Tracking System
- Users can only mark the days when the habit was performed
- Records how many times the habit was performed each day
- Days when the habit was not performed are automatically left blank
- Provides success percentage to the user
- **Ultra-flexible PIN system (3-8 digits)**

### 🎯 Progressive Goal System (Gradual & Infinite)
- Initial goals start short-term (3 days)
- Each completed goal makes the next one longer
- The system works in an infinite loop
- Success percentage is dynamically updated with each completed goal

### 📈 Revolutionary Visual Feedback
- Overall progress shown with glassmorphism line charts
- Drops, rises and stability can be easily observed on charts
- **Scrollable chart system** with horizontal navigation
- **Mobile-optimized responsive design**

### 🧱 Advanced Level System
- Level increases as habits are not performed
- When habits are repeated, success percentage decreases and level drops proportionally
- User never returns completely to zero, motivation is preserved
- Level increase is given as a reward for each successfully completed goal

### 🔐 Enhanced Security Features
- **Ultra-flexible PIN system: 3-8 digits**
- Maximum 3 login attempts per IP address
- Protection against brute-force attacks
- **Automatic security warnings** for shorter PINs

### 🎨 Revolutionary Design v3.0
- **Glassmorphism Design Language**
- Advanced backdrop blur effects
- Modern gradient backgrounds
- Micro-interactions and animations
- **Mobile-first responsive design**
- Inter font family integration

## 🛠 Technical Infrastructure

- **Backend**: PHP (CodeIgniter 4 Framework)
- **Database**: MySQL
- **Frontend**: HTML5, **Revolutionary CSS with Glassmorphism**, JavaScript
- **Charts**: Chart.js with enhanced scrolling
- **Security**: CodeIgniter's built-in session, throttle and filter systems
- **Design**: **Omar BYA Personal Style Standards**

## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/username/habittracker.git
```

2. Install dependencies:
```bash
composer install
```

3. Configure the `.env` file:
```bash
cp env .env
```
Then open the `.env` file and set up your database information.

4. Create database tables:
```bash
php spark migrate
```

5. Run the application:
```bash
php spark serve --port=8080
```

## 📱 Usage

1. Create a new account or sign in with your existing account
2. Use the "Add New Habit" button to define the habit you want to break
3. Use the "Add Entry" button to record days when you performed the habit
4. Track your progress with graphics and statistics
5. **Level up by completing goals**
6. **Enjoy the revolutionary glassmorphism experience**
